# Activity Log

Use one entry per work session. Keep sensitive values out of this file.

| Date/time | Milestone | Activity | Result | Evidence filename |
|---|---|---|---|---|
| YYYY-MM-DD | M1 | [Describe authorised activity] | [Observed result] | [redacted screenshot/log] |

## Evidence naming convention

Use clear, non-sensitive names, for example:
- `M1-01-scope-confirmation.png`
- `M1-02-redacted-observation.png`
- `M2-01-file-properties-redacted.png`
- `M3-01-redacted-exposure-proof.png`
- `M4-01-report-summary.png`

Do not put patient names, identifiers, salary values, credentials, tokens, or confidential records in filenames.
